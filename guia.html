Começando com Claude Code

Um guia para quem nunca abriu um terminal na vida. Você vai abrir o Terminal exatamente uma vez — e nunca mais.

≈ 5 minutos 6 passos Não dá pra quebrar nada
Leia antes de tudo

O Claude Code não funciona no plano gratuito. Você precisa de uma assinatura Claude Pro (~US$ 20/mês) ou Max. Assine em claude.ai/upgrade antes de continuar — sem isso, nenhum dos passos abaixo vai funcionar.

1

Abra o Terminal

Aperte ⌘ Cmd + Espaço, digite Terminal, aperte Enter.

Vai abrir uma janela com texto e um cursor piscando. Ela parece intimidadora e não é. É só uma caixa onde você cola uma frase e aperta Enter — como a barra de busca do Google, só que mais feia.

2

Cole esta linha e aperte Enter

Copie exatamente isto
curl -fsSL https://raw.githubusercontent.com/jarantes-prog/claude-code-starter-pack/main/setup.sh | bash

Cole com ⌘ Cmd + V e aperte Enter.

Se algo der errado

Cole a mesma linha de novo. O script foi feito pra ser repetido: ele nunca apaga nada, pula o que já está pronto e continua de onde parou.

Nada de misterioso — o script conta cada coisa que faz, em português:

4

Instale o aplicativo Claude

No fim, o script abre o download no seu navegador. Salve o arquivo Claude.dmg, clique duas vezes nele, e arraste o ícone do Claude para a pasta Aplicativos.

É a instalação normal de qualquer app de Mac. Se o navegador não abrir sozinho, vá em claude.ai/download.

Pode fechar o Terminal agora. Você não precisa mais dele.

5

Abra o Claude e vá na aba Code

Faça login com a conta da sua assinatura. No topo da janela existem três abas — Chat, Cowork e Code. Clique em Code.

Depois abra a pasta Documents › Meu-Vault.

Por que escolher uma pasta

O Claude Code sempre trabalha dentro de uma pasta. Ele lê os arquivos que estão ali e segue as regras escritas no Welcome.md daquela pasta. Escolher a pasta é dizer “é aqui que a gente trabalha hoje”.

6

Seu primeiro ingest

Esta é a parte que faz a ficha cair. Pegue um artigo que você leu de verdade essa semana, arraste o arquivo para a pasta raw/ do vault, volte no Claude e escreva duas palavras:

Digite isto
ingest it

Agora assiste. Ele lê o arquivo inteiro, conversa com você sobre o que achou importante, escreve um resumo citando as fontes, cria uma página separada pra cada pessoa, empresa e conceito que apareceu, conecta tudo com links e atualiza o índice.

→
Um artigo vira de 5 a 15 páginas conectadas. Isso é normal. É esse acúmulo que faz o vault valer a pena.

Repare no que você não fez: não pediu “crie uma página sobre X”. Você disse duas palavras, e as regras do Welcome.md fizeram o resto.

“me explica esse erro em português e me diz exatamente o que fazer”.

Getting started with Claude Code

A guide for people who have never opened a terminal. You'll open the Terminal exactly once — and never again.

≈ 5 minutes 6 steps You can't break anything
Read this first

Claude Code does not work on the free plan. You need a Claude Pro (~$20/month) or Max subscription. Subscribe at claude.ai/upgrade before continuing — without it, none of the steps below will work.

1

Open the Terminal

Press ⌘ Cmd + Space, type Terminal, press Enter.

A window opens with text and a blinking cursor. It looks intimidating and it isn't. It's just a box where you paste a line and press Enter — like a Google search bar, only uglier.

2

Paste this line and press Enter

Copy exactly this
curl -fsSL https://raw.githubusercontent.com/jarantes-prog/claude-code-starter-pack/main/setup.sh | bash -s -- --lang en

Paste with ⌘ Cmd + V and press Enter.

If something goes wrong

Paste the same line again. The script is built to be repeated: it never deletes anything, skips whatever is already done, and picks up where it left off.

3

This is what you'll see

Nothing mysterious — the script narrates every single thing it does:

4

Install the Claude app

At the end, the script opens the download in your browser. Save the Claude.dmg file, double-click it, and drag the Claude icon into your Applications folder.

It's the normal way any Mac app installs. If the browser doesn't open on its own, go to claude.ai/download.

You can close the Terminal now. You don't need it anymore.

5

Open Claude and go to the Code tab

Log in with your subscription account. At the top of the window there are three tabs — Chat, Cowork, and Code. Click Code.

Then open the folder Documents › My-Vault.

Why you pick a folder

Claude Code always works inside a folder. It reads the files there and follows the rules written in that folder's Welcome.md. Picking the folder is how you say “this is where we're working today”.

6

Your first ingest

This is the part where it clicks. Take an article you actually read this week, drag the file into the vault's raw/ folder, go back to Claude, and type two words:

Type this
ingest it

Now watch. It reads the whole file, talks to you about what it found important, writes a summary citing sources, creates a separate page for every person, company and concept that came up, links it all together, and updates the index.

→
One article becomes 5 to 15 linked pages. That's normal. That compounding is what makes the vault worth having.

Notice what you didn't do: you never said “create a page about X”. You said two words, and the rules in Welcome.md did the rest.

When you get stuck

The trick that solves 80% of cases

Copy the error message, paste it into Claude, and write:
“explain this error to me and tell me exactly what to do”.

If you seeDo this
command not found: claude Quit the Terminal (⌘+Q), reopen it, paste the line again.
requires a Pro or Max account You're on the free plan. Subscribe at claude.ai/upgrade.
It asks permission for something Inside the vault, go ahead. Outside it, ask “why do you need that?”
It wrote something wrong Tell it, or edit the file by hand. It's just markdown — the vault is yours.
It deleted something by accident Type /rewind to roll the conversation and files back.
Nothing works In the Terminal, run claude doctor. Then send a screenshot.

You're not going to break anything. The realistic worst case is a badly written wiki page — and that's fixed by editing a text file. Go ahead and experiment.
