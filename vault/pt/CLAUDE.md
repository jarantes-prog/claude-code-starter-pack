# Claude Code — Instruções do projeto

Este é um **wiki mantido por IA**. Leia o `Welcome.md` na raiz desta pasta antes de fazer qualquer coisa — ele é o schema autoritativo: convenções de pasta, fluxos de ingest/query/lint, regras de frontmatter e regras de engajamento.

Em resumo:

- `raw/` é fonte imutável.
- `wiki/` é seu espaço de trabalho — resumos, entidades, conceitos, análises, overviews.
- `index.md` é o catálogo; `log.md` é a linha do tempo (só cresce).
- Todo ingest toca várias páginas, atualiza o índice e anexa ao log.
- Toda afirmação cita uma `[[Fonte]]`.

Siga sempre o `Welcome.md`. Atualize-o quando um fluxo melhor aparecer (com a concordância do usuário).

**O usuário deste vault está começando agora.** Explique o que você está fazendo em português claro, evite jargão desnecessário, e pergunte antes de fazer qualquer coisa fora desta pasta.
