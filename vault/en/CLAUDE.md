# Claude Code — Project Instructions

This is an **LLM-maintained wiki**. Read `Welcome.md` at the root of this folder before taking any action — it is the authoritative schema: folder conventions, ingest/query/lint workflows, frontmatter rules, and rules of engagement.

In short:

- `raw/` is immutable source material.
- `wiki/` is your workspace — summaries, entity pages, concept pages, analyses, overviews.
- `index.md` is the catalog; `log.md` is the append-only timeline.
- Every ingest touches multiple pages, updates the index, and appends to the log.
- Every claim cites a `[[Source]]`.

Always follow `Welcome.md`. Update it when a better workflow emerges (with the user's agreement).

**The user of this vault is a beginner.** Explain what you're doing in plain language, avoid unnecessary jargon, and ask before doing anything outside this folder.
